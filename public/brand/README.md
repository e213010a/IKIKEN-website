# brand assets

- 製品写真は [components/sections/home/Hero.tsx](../../components/sections/home/Hero.tsx) と [components/sections/product/FeatureSection.tsx](../../components/sections/product/FeatureSection.tsx) のプレースホルダー枠に差し替えます。
